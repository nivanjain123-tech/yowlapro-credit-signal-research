# AI usage

I used Claude (through the Claude Code desktop app) while working on this.

It helped me read the starter kit, find and fix the bugs in `helpers.py`, write the SQL queries, the analysis code and the notebook, and draft the report. It also ran extra checks on my results (an independent rebuild in SQL, permutation tests, a timing placebo, and sector controls, which is how we found that `f_39` was weak).

The decisions were mine: which two hypotheses to register, locking them in the portal, downloading the holdout only after that, and reporting H2 as inconclusive rather than claiming it. I went through the outputs myself.

Claude read the starter kit files on my machine, and later the holdout files after I locked.
